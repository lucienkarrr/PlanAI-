# PlanAI-
Проектирование ИИ-помощника для подготовки плана образовательного мероприятия
Учебный проект бизнес-анализа: проектирование ИИ-помощника для подготовки плана небольшого образовательного мероприятия. Проект включает анализ потребностей, требования, моделирование, прототипирование и оценку результатов генерации. Стадия: постановка задачи и выявление потребностей.
